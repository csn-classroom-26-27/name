## 1. Цикли

Умовні оператори виконують певні оператори, якщо виконуються певні умови.

Цикли виконують певні оператори, поки виконуються певні умови.

C++ має три типи циклів: `while`, `do-while` і `for`.

### 1.1. Цикл `while`

Цикл `while` має форму, подібну до умови `if`:

```cpp
while(умова) {
  інструкція1
  інструкція2
  ...
}
```

Поки виконується умова, блок операторів буде виконуватися неодноразово.
Якщо є лише одне твердження, фігурні дужки можна опустити.
Ось приклад:

```cpp
#include <iostream>

using namespace std;

int main() {
  int x = 0;

  while(x < 10)
    x = x + 1;

  cout << "x дорівнює " << x << "\n";
  
  return 0;
}
```

Ця програма надрукує `x дорівнює 10`.

### 1.2. Цикл `do-while`

Цикл `do-while` — це варіант, який гарантує, що блок операторів буде виконано принаймні один раз:

```cpp
do {
  інструкція1
  інструкція2
  ...
} while(умова);
```

Блок операторів виконується, а потім, якщо умова виконується, програма повертається до початку блоку.
**Фігурні дужки завжди потрібні.**
Також зверніть увагу на крапку з комою після умови `while`.

### 1.3. Цикл `for`

Цикл `for` працює як цикл `while`, але з деякими змінами в синтаксисі:

```cpp
for(ініціалізація; умова; інкремент) {
  інструкція1
  інструкція2
  ...
}
```

Цикл `for` призначений щоб змінна лічильника, яка **ініціалізується** на початку циклу та збільшується (або зменшується) на кожній ітерації циклу.
Фігурні дужки можна опустити, якщо є лише одна інструкція.
Ось приклад:

```cpp
#include <iostream>

using namespace std;

int main() {
  for(int x = 0; x < 10; x = x + 1)
    cout << x << "\n";

  return 0;
}
```

Ця програма роздрукує значення від $0$ до $9$, кожне в окремому рядку.

Якщо змінну лічильника вже визначено, немає потреби визначати нову в частині ініціалізації циклу `for`.
Отже, допустимо мати наступне:

```cpp
#include <iostream>

using namespace std;

int main() {
  int x = 0;

  for(; x < 10; x = x + 1)
    cout << x << "\n";

  return 0;
}
```

Зауважте, що перша крапка з комою всередині дужок циклу `for` все ще є обов’язковою.

Цикл `for` може бути виражений як цикл `while` і навпаки. Розуміючи це, цикл `for` має вигляд:

```cpp
for(ініціалізація; умова; інкремент) {
  інструкція1
  інструкція2
  ...
}
```

ми можемо написати еквівалентний цикл `while` як:

```cpp
ініціалізація

while(умова) {
  інструкція1
  інструкція2
  ...
  інкремент
}
```

Використовуючи приклад вище:

```cpp
#include <iostream>

using namespace std;

int main() {
  for(int x = 0; x < 10; x = x + 1)
    cout << x << "\n";

  return 0;
}
```

перетворюється на:

```cpp
#include <iostream>

using namespace std;

int main() {
  int x = 0;
  
  while(x < 10) {
    cout << x << "\n";
    x = x + 1;
  }

  return 0;
}
```

Крок інкрементації технічно може бути де завгодно всередині блоку операторів, але це гарна практика розміщувати його як останній крок, особливо якщо попередні оператори використовують поточне значення змінної лічильника.

### 1.4. Вкладені структури

Можна розмістити умови всередині інших умов, просто розмістивши їх структури всередині блоків операторів.
Це дозволяє більш складну поведінку програми.
Приклад:

```cpp
#include <iostream>

using namespace std;

int main() {
  for(int x = 0; x < 4; x = x + 1) {
    for(int y = 0; y < 4; y = y + 1)
      cout << y;
    cout << "\n";
  }

  return 0;
}
```

Ця програма надрукує чотири рядки $0123$.

### 1.5. Оператор `break` для переривання циклу

Використовується для виходу з будь-якого циклу.

Приклад для виведення перших десяти чисел більше нуля:

```cpp
int i = 1;

while (true) {
  if(i > 10) break;
  
  cout << i << "\n";
  
  ++i;
}
```

### 1.6. Оператор `continue` для пропуску ітерації циклу

Використовується для пропуску решти тіла циклу та переходу до наступної ітерації.

Приклад для виведення парних чисел в діапазоні від 0 до 10:

```cpp
for(int i = 0; i <= 10; ++i) {
  if(i % 2 != 0) continue; // пропускає непарні числа

  cout << i << "\n";
}
```

### 2.2. Базова статистика

Дано список з $N$ цілих чисел, знайдіть його середнє (як `double`), максимальне значення, мінімальне значення та діапазон.
Ваша програма спочатку запитає $N$, кількість цілих чисел у списку, який введе користувач.
Тоді користувач введе ще $N$-кількість чисел.

Ось приклад послідовності введення:
 
```sh
3 <-- N
2
1
3
```

Дано три числа: $2$, $1$, $3$. Результат має бути таким:

```cpp
Середнє: 2
Максимальне: 3
Мінімільне: 1
Діапазон: 2
```

### 2.3. Прості числа

Напишіть програму, яка зчитує число $N$ від користувача, а потім знаходить перші $N$ простих чисел.
Просте число – це число, яке має лише два дільники: одиницю та себе.

### 2.4 Кратність чисел

#### 2.4.1 Тернарний оператор

Напишіть програму, яка виконує нескінченний цикл.
У кожній ітерації циклу зчитуйте ціле число $N$ (оголошене як `int`), яке вводить користувач, виводьте $N/5$, якщо $N$ є невід’ємним і ділиться на $5$, і $-1$ в іншому випадку.
Для цього використовуйте тернарний оператор (`?:`). (Підказка: оператор модуля може бути корисним.)

#### 2.4.2 Оператор `continue`

Змініть код із 2.4.1 так, щоб у разі невдачі умови нічого не друкувалося.
Для цього використовуйте команду `if` і `continue` (замість тернарного оператора).

#### 2.4.3 Оператор `break`

Змініть код із 2.4.2, щоб дозволити користувачеві вийти з циклу, ввівши $-1$ або будь-яке від’ємне число.
Перед виходом з програми виведіть рядок «_До побачення!_».

#### 2.6.1. bob і dole

Спробуйте написати кілька прикладів із маленькими цифрами на папері, якщо ви застрягли.
(Підказка: подумайте про числа в двійковій системі числення – за основою $2$.
Як би ви виразили число як суму степенів $2$?
Вам також може бути корисно зауважити, що множення на $2n$ еквівалентно множенню на $2$ $n$ разів.
Слід також пам’ятати про розподільну властивість множення: $a(x + y) = ax + ay$)

```cpp
int bob, dole;
int accumulator = 0;

while (true) {
  if(dole == 0) break;
  accumulator += ((dole % 2 == 1) ? bob : 0);
  dole /= 2;
  bob *= 2;
}

cout << accumulator << "\n";
```
